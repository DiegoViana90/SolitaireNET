Politica de privacidade

Esta pagina resume como o SolitaireNET usa dados para manter os jogos funcionando.

Dados de jogo

O site pode salvar progresso no armazenamento local do navegador para permitir continuar uma partida. Esses dados ficam no dispositivo do jogador.

Login e ranking

Quando o login esta ativo, o site pode usar dados basicos da conta para identificar o jogador no ranking, como nome exibido e identificador de conta.

Cookies e anuncios

O site pode usar tecnologias de terceiros, como login, metricas ou anuncios, quando configuradas. Se anuncios forem ativados, parceiros de publicidade podem usar cookies ou identificadores conforme suas proprias politicas.

Contato

Para solicitar informacoes ou remocao de dados associados ao ranking, entre em contato pelo email dvkdeveloping@gmail.com.
