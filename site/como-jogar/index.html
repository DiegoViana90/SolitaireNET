Como jogar paciencia

Paciencia e um jogo de cartas classico para uma pessoa. No SolitaireNET, voce joga paciencia online gratis direto no navegador.

Objetivo

Leve todas as cartas para as quatro bases, separadas por naipe, comecando no As e terminando no Rei.

Movimentos basicos

  1. Vire cartas do monte para revelar novas opcoes.
  2. Mova cartas entre colunas alternando cores e seguindo ordem decrescente.
  3. Use espacos vazios para colocar reis e abrir novas sequencias.
  4. Envie ases e cartas seguintes do mesmo naipe para as bases.

Dicas rapidas

  • Priorize revelar cartas fechadas nas colunas.
  • Evite esvaziar uma coluna se voce nao tiver um rei para ocupar o espaco.
  • Antes de mover uma carta para a base, confira se ela ainda ajuda a liberar outras cartas.
