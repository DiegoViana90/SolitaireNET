Politica de privacidade

Esta pagina resume como o paciencia . net usa dados para manter os jogos funcionando.

Dados de jogo

O site pode salvar progresso no armazenamento local do navegador para permitir continuar uma partida. Esses dados ficam no dispositivo do jogador.

Login e ranking

Quando o login esta ativo, o site pode usar dados basicos da conta para identificar o jogador no ranking, como nome exibido e identificador de conta.

Cookies e anuncios

O site pode usar tecnologias de terceiros, como login, metricas ou anuncios, quando configuradas. Se anuncios forem ativados, parceiros de publicidade, incluindo o Google, poderao usar cookies, identificadores ou tecnologias semelhantes para exibir e medir anuncios.

O uso de cookies de publicidade pode permitir anuncios personalizados com base na visita a este ou a outros sites. O visitante pode controlar a personalizacao de anuncios pelas Configuracoes de anuncios do Google. As politicas dos parceiros tambem podem se aplicar.

Visitantes de regioes que exigem consentimento podem receber uma mensagem de privacidade antes da ativacao de anuncios personalizados. As preferencias podem ser alteradas quando a opcao de privacidade estiver disponivel no site.

Seguranca e retencao

Os dados sao usados apenas pelo tempo necessario para operar os jogos, manter o ranking, responder ao suporte e cumprir obrigacoes legais. Nenhum site conectado a internet pode garantir seguranca absoluta, mas sao adotadas medidas razoaveis para proteger os dados sob controle do projeto.
